LIneA provides the Brazilian astronomical community with access to high-performance computing (HPC) resources. These resources are designed to support research projects requiring significant computational power, storage, and the analysis of large volumes of astronomical data.

!!! info "Accessing the environment"
    Access to the HPC environment is done via the platform [Open OnDemand](https://ondemand.linea.org.br/) and is granted upon submission of a project summary—including a technical justification for the required resources—which is then evaluated by an internal technical-scientific committee. To request access, please contact the Service Desk ([helpdesk@linea.org.br](helpdesk@linea.org.br)) and follow the instructions sent via email.

The data available for analysis on our HPC resources includes public and private astronomical catalogs, as well as data from cosmological and astrophysical simulations. Other datasets may be made available upon request, subject to technical feasibility and data-sharing policies.

Data hosted in the LIneA HPC environment is organized and accessible via the **Lustre** distributed file system, connected to an **InfiniBand** network, enabling users to read and write data efficiently during their analyses.

To access information about the datasets available in the HPC environment, please navigate using the menu on the left.

!!! warning "Restricted access"
    In compliance with LIneA's security policy and the proprietary data access policies of the supported projects, some information regarding the data available in the HPC environment is restricted to authorized users.
