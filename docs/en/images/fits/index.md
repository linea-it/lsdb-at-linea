# FITS

**[FITS](https://fits.gsfc.nasa.gov/)** (Flexible Image Transport System) is a standard format for storing and exchanging astronomical data.

This section lists surveys with FITS image products available at LIneA. Each survey has its own page describing the available products — such as single-epoch exposures, coadded images, and auxiliary products — as well as band coverage and access level, when applicable.
