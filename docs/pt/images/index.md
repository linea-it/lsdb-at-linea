# Imagens

O acesso às imagens astronômicas é realizado por meio de diferentes aplicações do LIneA Science Platform, conforme o tipo de imagem e o levantamento astronômico de origem.

Nesta seção você encontra:

- [HiPS](hips.md): imagens Hierarchical Progressive Surveys para visualização global e navegação
- [FITS](fits/index.md): imagens coadicionadas e de exposição única
    - [LSST DP1](fits/lsst_dp1.md): inventário dos produtos FITS disponíveis no LIneA

As imagens [FITS](fits/index.md) (Flexible Image Transport System) coadicionadas e de exposição única, acessíveis por cutouts no [Target Viewer](https://targetviewer.linea.org.br/), API no [Jupyter Hub](https://jupyter.linea.org.br/) ou processamento no ambiente HPC via [Open OnDemand](https://ondemand.linea.org.br).

Para um resumo dos conjuntos de imagens disponíveis, consulte a [página inicial](../index.md).
