# FITS

O **[FITS](https://fits.gsfc.nasa.gov/)** (Flexible Image Transport System) é um formato padrão para armazenamento e intercâmbio de dados astronômicos.

Esta seção reúne os levantamentos com produtos de imagem disponíveis em FITS no LIneA. Cada levantamento possui uma página própria descrevendo os produtos disponíveis — como exposições individuais, imagens coadicionadas e produtos auxiliares —, a cobertura por banda e o nível de acesso, quando aplicável.
