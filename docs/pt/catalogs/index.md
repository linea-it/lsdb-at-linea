# Catálogos

O acesso a dados tabulares (catálogos) é realizado por meio de diferentes aplicações do [LIneA Science Platform (LSP)](https://scienceplatform.linea.org.br/lsp), conforme o tamanho, o tipo ou os níveis de permissão de acesso estabelecidos pelo levantamento astronômico de origem.

Nesta seção você encontra:

- [LSDB Surveys](../lsdb/index.md): download e acesso programático a catálogos no formato [HATS](https://hats.readthedocs.io/en/stable/)
- [Banco de Dados](../database/index.md): consulta a catálogos via [User Query](https://userquery.linea.org.br/), [Jupyter Hub](https://jupyter.linea.org.br/) ou [TAP Service](https://userquery.linea.org.br/cms/services/scripted-access/)

Para um resumo dos catálogos disponíveis, consulte a [página inicial](../index.md).
