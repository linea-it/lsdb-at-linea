# FITS

**[FITS](https://fits.gsfc.nasa.gov/)** (Flexible Image Transport System) es un formato estándar para almacenar e intercambiar datos astronómicos.

Esta sección reúne los relevamientos con productos de imagen disponibles en FITS en LIneA. Cada relevamiento tiene una página propia que describe los productos disponibles — como exposiciones individuales, imágenes coadicionadas y productos auxiliares —, la cobertura por banda y el nivel de acceso, cuando corresponda.
